# Example University

Dieses Beispiel ist vollständig fiktiv.

Es zeigt, wie Studiengang-CompAIgnon durch Profile konfiguriert werden kann, ohne reale
hochschul- oder landesrechtliche Vorgaben mitzuliefern.

## Enthaltene Dateien

- `state-profile.yaml` – fiktives Landesprofil
- `institution-profile.yaml` – fiktives Hochschulprofil
- `rules.yaml` – Beispielregeln
- `terminology.yaml` – lokale Terminologie
- `contacts.yaml` – lokale Zuständigkeiten
- `knowledge/` – fiktive Beispielquellen

## Wichtig

Alle Werte sind Demonstrationswerte.

Insbesondere der in `rules.yaml` verwendete Wert für `hours_per_credit` ist
absichtlich frei erfunden, damit das Beispiel nicht versehentlich als
deutsche oder institutionelle Norm interpretiert wird.

Dieses Beispiel darf nicht als Prüfgrundlage für reale Studiengänge verwendet
werden.
