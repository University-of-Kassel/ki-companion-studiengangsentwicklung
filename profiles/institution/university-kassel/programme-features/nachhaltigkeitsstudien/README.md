# Programme-Feature: Nachhaltigkeitsstudien

Dieses Feature bildet die **Allgemeinen Bestimmungen für das Bachelor-Nebenfach
Nachhaltigkeitsstudien und die Integrierten Nachhaltigkeitsstudien der Universität Kassel
(AB NaS)** ab.

Es ist keine einzelne Studiengangsordnung. Die AB NaS kann mehrere Studiengänge bzw.
Curricula ergänzen.

## Aktivierung

Das Feature wird nur aktiviert, wenn der konkrete Studiengang die AB NaS tatsächlich nutzt.
Der Parameter `integration_mode` unterscheidet:

- `minor` – Bachelor-Nebenfach Nachhaltigkeitsstudien, 40 Credits
- `inas_a` – Integrierte Nachhaltigkeitsstudien A, 60 Credits
- `inas_b` – Integrierte Nachhaltigkeitsstudien B, 30 Credits
- `elective_focus` – Nachhaltigkeitsstudien-Schwerpunkt im Wahlbereich, 18 Credits

Eine bloße thematische Ausrichtung auf Nachhaltigkeit aktiviert dieses Feature **nicht**.

## Verhältnis zum Institutionsprofil

Das Feature ergänzt:

`profiles/institution/university-kassel/`

Insbesondere bleiben AB BAMA und andere allgemeine Kasseler Regeln parallel aktiv.
Feature-Regeln dürfen nicht auf Studiengänge übertragen werden, die die AB NaS nicht verwenden.
